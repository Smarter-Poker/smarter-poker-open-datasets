# Smarter.Poker Open Quantitative Poker Research Datasets (2026)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24095049.svg)](https://doi.org/10.5281/zenodo.24095049)

Open-access (`CC-BY-4.0`) CSV and JSON datasets covering North American live cardroom rake structures, Texas time-collection benchmarks, state-level poker room census tables, Malmuth-Harville Independent Chip Model (ICM) bubble factors, Progressive Knockout (PKO) and Mystery Bounty chip-equivalence models, Pot-Limit Omaha (PLO4/PLO5/PLO6) equity realization variance, and tournament structure pace metrics compiled by the Smarter.Poker Research Division.
